# Landslide EWS Frontend

React and TypeScript single-page application built with Vite. For the project overview and backend setup, see the [root README](../README.md).

## Commands

Install dependencies with `npm ci`, then use:

- `npm run dev` — start the Vite development server.
- `npm test` — run the frontend tests with Node's built-in test runner.
- `npm run build` — type-check and create the production build.
- `npm run lint` — run Oxlint.

The test command requires a recent Node.js release with `--experimental-strip-types` support.
